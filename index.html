Voxel Editor (Web prototype)

Status: Menunggu kamera...

Kontrol tangan:

  • Gerakkan jari telunjuk untuk menggerakkan kursor voxel (video kanan atas)
  • Pinch (jempol+telunjuk mendekat) untuk menambah voxel
  • Buka tangan untuk menghapus voxel
  • Gunakan mouse untuk mengorbit / zoom

Prototype — untuk produksi butuh penyempurnaan kalibrasi, smoothing, dan handling lighting/performance.
